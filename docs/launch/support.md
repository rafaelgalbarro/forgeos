# Support — ForgeOS 1.0

## Centro de soporte

Ruta: `/support`

Incluye artículos de ayuda, formulario beta compacto y enlaces útiles.

## Canales RC12

1. **Docs** — `/docs` y `/docs/quickstart`
2. **Status** — `/status` para estado de servicios
3. **Feedback widget** — botón flotante 💬 en páginas launch y `/os`
4. **Feedback local** — `localStorage` key `forgeos-feedback`

## Artículos incluidos

- Acceso a beta
- Primera venture
- Facturación (placeholder)
- Almacenamiento local
- Reset de cuenta local

## Escalación

En RC12 no hay ticket system externo. Feedback se guarda localmente para demos.
