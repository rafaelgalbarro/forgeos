# Value Stages

Catalog: `VALUE_STAGE_DEFINITIONS` in `src/core/domain/value/stages.ts`.

| Stage | Intent |
|-------|--------|
| `IDEA_VALUE` | Idea + hypothesis |
| `PROBLEM_VALIDATION` | Problem confirmed with sources |
| `SOLUTION_VALIDATION` | Solution pull / intent |
| `PRODUCT_VALIDATION` | Pilot / usage |
| `MARKET_VALIDATION` | Acquisition signals |
| `LAUNCH_READINESS` | Ops + launch criteria |
| `TRACTION` | Sustained usage/retention |
| `REVENUE` | Actual paying relationships |
| `PROFITABILITY` | Actual margin with costs |
| `SCALE` | Repeatable economics + ops |

Each stage defines: entry criteria, required evidence types, exit criteria, blocking risks, recommended experiments, confidence ceiling.
