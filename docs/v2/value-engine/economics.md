# Venture Economics

`VentureEconomics` fields (each typed money value where applicable):

- actual / projected revenue
- recurring revenue
- gross margin
- operating / AI / infra / acquisition / human cost
- total invested
- cost to next milestone
- runway
- expected value range

Every money value carries: currency, period, source, type (`ACTUAL`/`ESTIMATED`/`PROJECTED`), confidence, `updatedAt`.

Currency is the **venture-configured** ISO-4217 code (fixture uses EUR or USD per venture — never assumed globally).
