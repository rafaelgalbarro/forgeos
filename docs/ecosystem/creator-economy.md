# Creator Economy (RC9)

Mock catalog for creators publishing and selling ecosystem assets.

## Asset Types

- Skills
- Workers
- Departments
- Templates
- Knowledge
- Playbooks
- Business Models
- Plugins

## Revenue Model (mock)

- `revenueSharePct` — creator share (60–80%)
- `priceLabel` — display pricing
- `salesCount` — mock sales counter

## API

```typescript
import { listCreatorListings, getCreatorEconomyStats, publishListingDraft } from "@/lib/ecosystem";
```

All transactions are simulated — no real payments or payouts.
