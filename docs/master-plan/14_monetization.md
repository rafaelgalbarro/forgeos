# 14 — Monetización

## Modelo de negocio

ForgeOS monetiza el **tiempo y calidad del proceso venture** — no solo tokens de IA.

> *Hipótesis:* Fundadores pagan por estructura, persistencia y handoff — no por otro chat.

## Líneas de ingreso

| Línea | Descripción | Versión |
|-------|-------------|---------|
| SaaS mensual | Suscripción a la plataforma | v2+ |
| Planes por usuario | Seats en workspace | v4+ |
| Planes por workspace | Portfolio size, ventures activos | v4+ |
| Marketplace revenue share | Templates y workers premium | v8+ |
| Enterprise | SSO, compliance, SLA, private cloud | v9+ |
| Templates premium | Curados por ForgeOS | v4+ |
| Workers premium | Módulos IA especializados | v5+ |
| Deployment services | Forge Cloud + setup | v6+ |

## Estructura de planes (borrador)

| Plan | Target | Incluye |
|------|--------|---------|
| **Free** | Explorar | 1 venture, Intelligence, exports básicos |
| **Founder** | Indie | 3 ventures, IA Research/Product, Build Plan |
| **Studio** | Serial founders | 10 ventures, CEO brief, priority IA |
| **Team** | Micro studio | Seats, Board, colaboración |
| **Enterprise** | Corp innovation | SSO, audit, custom knowledge |

| Recurso | Free | Founder | Studio |
|---------|------|---------|--------|
| Ventures activos | 1 | 3 | 10 |
| IA calls/mes | Bajo | Medio | Alto |
| Exports | MD | MD+PDF+ZIP | Todo |
| AI CEO | No | Brief | Completo |
| AI Board | No | No | Pre-launch gates |
| Marketplace publish | No | Sí | Sí |

## Principios de pricing

1. **Free generoso en validación** — el valor se prueba antes de build
2. **Pagar por portfolio** — alinea con venture studio use case
3. **IA no es el producto** — es input cost, no value prop principal
4. **Enterprise = compliance + control** — no solo más tokens

## Anti-patrones de monetización

- Paywall antes de primera export útil
- Cobrar por decisión negativa (Do not build)
- Vender "éxito garantizado"
- Bundlear IA ilimitada sin límites de abuso
