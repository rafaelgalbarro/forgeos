# Program 6090 — Company Creation Command Center

Canonical route: `/company/[ventureId]`.

This package documents the V2 server-side read model and the unified visual command center that consolidates company creation state across venture, mission, output, build, preview, release, deployment, approvals, blockers, and next actions.

- Quick View: header, health, map, visual outputs, blockers, next actions
- Detailed View: all sections A-K with provenance and validations
- Reality classification: explicit labels per section and key artifacts
- Deployment safety: never reports real deployed state without credentials
