# ForgeOS Master Plan v1.0

**El sistema operativo para crear, validar, construir, lanzar y escalar empresas digitales con IA.**

---

## Qué es este directorio

`docs/master-plan/` es la **constitución estratégica** de ForgeOS Platform. Define visión, arquitectura, módulos, gobernanza (AI CEO / AI Board), portfolio, monetización y roadmap de versiones.

No sustituye a `docs/brain/` (especificación del cerebro operativo v0.1), sino que la **contextualiza** dentro de una plataforma completa.

## Relación con código actual

ForgeOS v0.1 implementa un subconjunto del Master Plan:

- Forge Discovery, Intelligence, Research, Product (parcial)
- Venture Simulator, Build Plan, Export
- Workers heurísticos + IA selectiva (Research/Product)
- Forge DNA en localStorage

El Master Plan describe el **destino**; el código describe el **presente**.
