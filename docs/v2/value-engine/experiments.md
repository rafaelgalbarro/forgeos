# Experiment Engine

## States

`DRAFT` → `PLANNED` → `RUNNING` → `COMPLETED` | `INVALID` | `CANCELLED`

## Types

`INTERVIEW`, `LANDING_PAGE`, `WAITLIST`, `PRICING_TEST`, `PAID_CAMPAIGN`, `OUTREACH`, `DEMO`, `PILOT`, `CONCIERGE_MVP`, `PRODUCT_TEST`, `RETENTION_TEST`, `UNIT_ECONOMICS_TEST`

## Required fields

hypothesis, audience, method, optional budget/duration, success/failure criteria, evidence, result, learning, next action.

`CompleteValueExperiment` may invalidate with reason instead of completing.
