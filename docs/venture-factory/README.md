# Venture Factory RC7

ForgeOS Venture Factory transforms an idea into a complete company — not just an app. Full pipeline from idea to revenue dashboard.

## Quick start

1. Open `/venture-factory`
2. Enter: **Crea una empresa de gafas premium**
3. Click **Crear empresa**
4. Watch the 18-stage pipeline simulation
5. Review output panels: naming, market, pricing, PRD, architecture, deployment, marketing, sprint 1, revenue

## Mode

**Dry-run only** — no production execution unless existing platform flags enable real execution elsewhere.

## Lab

Engineering harness: `/lab/venture-factory`

| Module | Purpose |
|--------|---------|
| `market-validator` | TAM/SAM/SOM + competitors |
| `business-model` | Business Model Canvas |
| `pricing-engine` | Plans + unit economics |
| `naming-generator` | Company name + domain |
| `brand-generator` | Identity, colors, tone |
| `landing-generator` | Landing copy preview |
| `product-generator` | PRD + sprint 1 |
| `architecture-generator` | Stack + diagram |
| `software-plan-generator` | Frontend/backend/database/UX |
