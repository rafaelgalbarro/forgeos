## Criterios de éxito por versión

| Versión | Pregunta clave |
|---------|----------------|
| v1 | ¿Un fundador completa idea → export útil? |
| v2 | ¿El CEO ahorra tiempo de priorización? |
| v3 | ¿El Board cambia decisiones reales? |
| v4 | ¿Usuarios mantienen ≥3 ventures? |
| v5 | ¿Build Plan → repo sin fricción? |
| v6 | ¿Primer venture lanzado vía ForgeOS? |
| v7 | ¿Métricas informan decisiones en app? |
| v8 | ¿Creadores ganan dinero? |
| v9 | ¿Enterprise paga anual? |
| v10 | ¿Autonomía sin incidentes de confianza? |

## Flexibilidad

El roadmap es **guía, no contrato**. Sprints pueden reordenar dentro de una versión; no saltar gates de confianza (auth antes de cloud, etc.).
