# Intelligence Layer Roadmap

## Release 0.5 (Current)

- [x] Venture memory snapshots
- [x] Decision engine with auto-milestones
- [x] Timeline builder
- [x] Heuristic pattern engine
- [x] Learning engine
- [x] Portfolio aggregation
- [x] Insight and recommendation generators
- [x] CEO memory structure (storage only)
- [x] Knowledge evolution wrapper
- [x] Memoria UI panel in Venture Workspace

## Release 0.6 — Enhanced Intelligence

- [ ] Cross-venture decision dependency graph
- [ ] Weighted pattern confidence from historical outcomes
- [ ] Export memory/decisions as JSON/CSV
- [ ] Notification hooks when patterns detected

## Release 0.7 — AI CEO Preparation

- [ ] Wire CEO memory to briefing generation (external AI, opt-in)
- [ ] Priority scoring from portfolio insights
- [ ] Weekly digest from accumulated learnings
- [ ] Knowledge evolution auto-tagging from venture outcomes

## Release 1.0 — AI CEO

- [ ] CEO agent reads portfolio memory + decisions
- [ ] Autonomous priority recommendations
- [ ] Board-ready briefings from accumulated intelligence
- [ ] Feedback loop: CEO decisions → venture memory

## Evolution Path

```
0.5 Heuristics + localStorage
  → 0.6 Weighted history + exports
    → 0.7 CEO structure + opt-in AI briefings
      → 1.0 Full AI CEO with memory-informed decisions
```

The current layer is designed so each module can be upgraded independently without breaking venture storage or existing engines.
