# Information Architecture

Sections A-K are rendered in one canonical panel:

- A `Company Header`
- B `Creation Health`
- C `Executive Summary`
- D `Products`
- E `Creation Map`
- F `Visual Outputs`
- G-H `Technical Foundation` and `Business Assets`
- I `QA / Validation`
- J `Release + Deployment`
- K `Activity, Blockers, Approvals, Next Actions`

Navigation includes quick/detailed modes and domain filtering.
