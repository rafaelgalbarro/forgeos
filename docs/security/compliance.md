# Compliance Enterprise

Checklist GDPR y SOC2 en `lib/enterprise/compliance-engine.ts`.

## Estados

- `ready` — cumplimiento demo completo
- `partial` — parcialmente implementado
- `pending` — pendiente

El plan `enterprise` desbloquea más ítems en ready/partial.

## Frameworks

- **GDPR** — DPA, exportación, olvido, consentimiento
- **SOC2** — acceso, auditoría, cifrado, incidentes
