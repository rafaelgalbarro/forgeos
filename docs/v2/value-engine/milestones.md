# Value Milestones

Examples: 10 interviews, 5 confirmed problems, landing published, 100 signups, 10 demos, first pilot, first customer, €1K/€10K MRR, validated gross margin, 90-day retention, repeatable operations.

## Fields

target, current, optional due date, evidence requirements, status, confidence, blocker, owner, cost to milestone (typed money with value type).

Completion with evidence requirements **fails** if no evidence is linked.
