# 00 — Índice del Master Plan

**ForgeOS Master Plan v1.0**

## Definición

> **ForgeOS Platform** es el sistema operativo para crear, validar, construir, lanzar y escalar empresas digitales con IA.

No es un generador de código. No es un Notion con chat. Es un **AI Venture Studio**: un entorno donde ideas se convierten en ventures con gobernanza, documentación, decisión y handoff técnico.

## Principios transversales

1. **Claridad antes de construir** — validar antes de escalar ingeniería
2. **El usuario decide; ForgeOS recomienda** — gobernanza, no autoritarismo
3. **Honestidad epistémica** — hipótesis explícitas, sin métricas inventadas
4. **Modularidad** — cada módulo reemplazable sin romper el OS
5. **Handoff real** — salida usable en Cursor, Claude o equipo humano
