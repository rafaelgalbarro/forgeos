# Flujo demo Enterprise

## Pasos obligatorios

1. **Crear organización** — nombre y plan inicial
2. **Crear equipo** — p.ej. "Producto"
3. **Asignar roles** — usuarios demo con owner/admin/member
4. **Ver permisos** — matriz RBAC
5. **Ver uso** — métricas de tokens, storage, API
6. **Ver billing** — plan y precio mock
7. **Ver auditoría** — log de acciones

## Atajo

Botón **Ejecutar demo completo** en `/enterprise` o **Seed demo** en `/lab/enterprise`.

## Reset

`resetDemoFlow()` en `lib/enterprise/demo-flow.ts` limpia estado sandbox.
