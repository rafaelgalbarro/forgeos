# Transparent Assessment

Assessments explain per dimension:

- evidence considered
- missing evidence
- confidence
- optional score (if used)
- status
- risk / recommendation notes

If a score is used:

- formula is stored (`compositeFormula` / per-dimension `scoreFormula`)
- weights are stored
- missing data is listed
- score **must not exceed** `confidence * 100`

There is **no** black-box portfolio rank score.
